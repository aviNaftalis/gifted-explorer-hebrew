# 🧠 אתגר המחוננים

אפליקציית תרגול אינטראקטיבית להכנה למבחן המחוננים שלב ב׳ לילדי כיתה ב׳.

## 🌐 [נסו עכשיו!](https://aviNaftalis.github.io/gifted-explorer-hebrew/)

## מה יש באפליקציה?

- **300 שאלות** — 50 שאלות בכל קטגוריה:
  - 🔗 יחסי מילים
  - ✏️ השלמת משפטים
  - 🧮 בעיות בחשבון
  - 🔢 סדרות מספרים
  - 🌍 ידע כללי (פתגמים, ביטויים, יוצא דופן)
  - 🔷 רצפי צורות (עם 50 איורי SVG)
- **מצב תרגול** — בחירת קטגוריה, מבחנים של 10 שאלות, טיימר אופציונלי
- **מבחן לדוגמה** — סימולציה של מבחן מחוננים אמיתי עם 5 פרקים מתוזמנים (12 דקות לכל פרק)
- **מעקב התקדמות** — היסטוריית ציונים

## טכנולוגיות

- React + TypeScript + Vite
- Tailwind CSS + shadcn/ui
- Framer Motion
- GitHub Pages
